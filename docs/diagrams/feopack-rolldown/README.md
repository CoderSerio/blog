# Rolldown article diagrams

These four architecture specifications are authored with Archify. The article embeds canonical SVG exports with light/dark theme support. Click an image to open it at full size.

Arrows point from a consumer to the module or chunk it depends on. These are explanatory layouts, not a claim that every configuration produces these exact chunks.

To regenerate, use the installed Archify skill: validate each JSON with `--quality showcase`, deliver an HTML viewer, run its visual check, then use the viewer’s Export → SVG action. Save the SVG in `public/diagrams/feopack-rolldown/` using the matching basename.
